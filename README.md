# Captura local para Android

App para registro simple de equipo.

[Descargar ZIP de instalacion](https://github.com/MxJAAR/captura-local/releases/latest/download/android-local.zip)

[Instrucciones de instalacion manual](android-local/INSTALACION-MANUAL.md)

Un servidor Android independiente por centro. Los datos y las credenciales permanecen en cada telefono. `start` comprueba actualizaciones firmadas antes de iniciar; sin Internet sigue con la version instalada. `stop` apaga el servidor.

El ZIP incluye las dependencias de mDNS. No incluye bases de datos, credenciales ni claves privadas.
